Assignment 4: Advertising Budget & Sales Data App — Linear Regression, SGD, and Random ForestThis project builds an interactive Streamlit Data App (GitHub Repository: ssj1469/Advertising-Budget-Sales-Dashboard) on the Kaggle Advertising Dataset (ashydv/advertising-dataset) to implement, tune, and compare three machine learning regression models: Linear Regression (OLS), Stochastic Gradient Descent (SGDRegressor), and Random Forest (RandomForestRegressor).1. Dataset & Decision ContextSource: Kaggle Advertising Dataset (ashydv/advertising-dataset) (advertising.csv, 200 market observations, 4 numeric columns):TV: TV advertising budget ($ thousands, mean 147.06, range 0.7–296.4)Radio: Radio advertising budget ($ thousands, mean 22.99, range 0.3–49.6)Newspaper: Newspaper advertising budget ($ thousands, mean 30.50, range 0.3–114.0)Sales: Product sales outcome (thousands of units, mean 15.12, range 1.6–27.0)Decision Persona: Designed for a marketing manager reviewing weekly advertising channel allocations and evaluating how linear and non-linear regression models forecast sales across TV, Radio, and Newspaper budgets.2. Machine Learning Models & Methodology (app.py)A. Preprocessing & Data SplittingPredictor Selection: Interactive sidebar selection for TV, Radio, and Newspaper (default: all three channels).Train/Test Split: Configurable test set ratio (test_size, default 0.20, i.e., 160 training markets and 40 test markets) and random seed (random_state, default 42).Feature Standardization (StandardScaler): Applied inside a scikit-learn Pipeline for both LinearRegression and SGDRegressor so that stochastic gradient updates converge reliably and standardized feature weights can be compared directly.B. Three Regression Models ComparedOrdinary Least Squares Linear Regression (LinearRegression)Fits the exact closed-form linear model $\hat{y} = \beta_0 + \beta_{\text{TV}}\text{TV} + \beta_{\text{Radio}}\text{Radio} + \beta_{\text{Newspaper}}\text{Newspaper}$.Full-dataset unscaled OLS equation:
$$\text{Sales} = 4.6925 + 0.0548 \times \text{TV} + 0.1030 \times \text{Radio} - 0.0001 \times \text{Newspaper}$$Achieves full-dataset $R^2 = 0.8952$ (RMSE $= 1.7131$, MAE $= 1.2742$), showing that TV and Radio account for almost all linear explanatory power while Newspaper has a near-zero marginal effect once TV and Radio are controlled for.Stochastic Gradient Descent Regressor (SGDRegressor)Iteratively minimizes the squared error loss using stochastic gradient descent on standardized features.Sidebar controls allow tuning learning_rate (invscaling, constant, adaptive), initial learning rate eta0 (0.0001–0.1), max_iter (100–5000), regularization penalty (l2, l1, elasticnet, None), and alpha.Random Forest Regressor (RandomForestRegressor)Non-linear ensemble of decision trees trained via bootstrap aggregation (bagging), capturing non-linear saturation and cross-channel synergy effects between TV and Radio spend.Sidebar controls allow tuning n_estimators (10–500), max_depth (2–20), and min_samples_split (2–20).3. Dashboard TabsTab 1 — Exploratory Dashboard: Displays three headline KPI cards (Average sales, Average total ad spend, Strongest historical channel), a horizontal bar chart comparing Pearson correlations with Sales (TV = 0.90, Radio = 0.33, Newspaper = 0.16), and an interactive single-channel scatter plot with a 1D OLS trend line.Tab 2 — Model Comparison (LR vs. SGD vs. RF): Compares Train $R^2$, Test $R^2$, Test RMSE, and Test MAE across all three models, alongside an Actual vs. Predicted Sales scatter plot and a grouped error comparison bar chart.Tab 3 — Coefficients & Feature Importance: Compares standardized regression weights between Linear Regression and SGD Regressor, displays the unscaled OLS regression equation, and plots Random Forest Feature Importances.Tab 4 — Interactive Budget & Sales Simulator: Provides interactive budget sliders for TV, Radio, and Newspaper to compare real-time sales predictions across all three models.4.
